This file is the source of truth for AI agents working on this repository.

## Project
Infra Lang is an Infrastructure-as-Code DSL. Compiles one `.infra` file to:
Kubernetes, Helm, Docker Compose, Terraform (AWS/GCP/Azure), GitHub Actions.
Stack: Python 3.11+, Lark (LALR grammar), Typer CLI, pygls LSP, VS Code
extension. Release state: **v0.1.1 — published on PyPI as `infra-lang`
(2026-08-20)**, public repo. A BOM fix and new `import`/`doctor` commands
landed after v0.1.0.

**Canonical repo:** `github.com/TuviDev/infra-lang` (docs at
`TuviDev.github.io/infra-lang`). The old `kakukpl` URLs were migrated to
`TuviDev` in commit `52179f1`/release-prep; **never reintroduce `kakukpl`**
(deprecated owner handle, 301-redirects to TuviDev).

**HEAD as of post-release handoff:** the post-release cleanup commit (removes
`PUBLISH.md`, updates install docs to `pip install infra-lang`). Repo clean.
**No git remote is configured** in the sandbox (push/tag needs the owner's own
credentials).

## Environment
- **pygls MUST be `1.3.1`** (2.x has a different API and silently skips the LSP
  tests, dropping coverage). Always re-pin after `pip install -e .[dev]`:
  `pip install "pygls==1.3.1" "lsprotocol==2023.0.1"`.
- `lsprotocol` MUST be `2023.0.1`.
- Python 3.11+ minimum (3.11/3.12/3.13 tested in CI).
- `pytest-xdist` required for parallel tests (`-n auto`).
- The sandbox env **resets between context windows**: reinstall deps, re-build
  `dist/` (`python -m build`), re-compile `vscode-infra-lang/out/extension.js`
  (`npm ci && npm run compile`) or `test_publish_readiness.py` and
  `test_vscode_extension.py` fail.

## Encoding (CRITICAL)
- **Every `.read_text()` MUST pass `encoding="utf-8"`**.
- **Every `open(path, "r")` MUST pass `encoding="utf-8"`**.
- Windows default encoding is cp1252, which crashes on UTF-8 docs (real CI bug,
  fixed in `922c2f9`). Grep for `.read_text()` without `encoding=` and `open(`
  without `encoding=` before committing.
- Also apply `encoding="utf-8"` to subprocess `text=True` calls
  (`encoding="utf-8", errors="replace"`) so non-ASCII kubectl/helm output never
  crashes on Windows.

## LSP (S31–S39)
- Server auto-advertises capabilities via pygls `@server.feature` decorators
  (completion, hover, definition, references, rename, semanticTokens,
  signatureHelp, documentHighlight, foldingRange, formatting, codeAction).
  No manual capability registration needed.
- Cross-file navigation uses `workspace_index` (on-disk scan on `initialized`,
  thread-pool, bounded to 1000 files / 1 MB, tolerant of malformed).
- **Position parameters MUST be clamped to line length** (a cursor past the
  end of a short line crashed on Windows — fixed in S28). Always
  `max(0, min(char, len(line)))`.
- Semantic tokens: line-based tokenizer (`semantic_tokens.py`), never AST-based
  (tolerant of malformed), delta-encoded.
- Word-boundary for rename/highlight: `(?<![A-Za-z0-9_-])...(?![A-Za-z0-9_-])`
  (`-`/`_` are valid in identifiers).

## Backends
- All backends inherit `Backend` (ABC in `base.py`); YAML backends also use
  `BaseYAMLBackend`. Interface: `get_version()`, `compile(program)`,
  `compile_service(node)`, `compile_database(node)`.
- Use `_labels(name)` helper for K8s-style labels (name + managed-by).
- **Multi-port Services need `name: tcp-<port>`** (K8s API requirement; was a
  real bug — Service and queue/RabbitMQ paths).
- **Secret `data:` values MUST be base64-encoded** (was a real bug). Use
  `stringData` for plain text (db credentials).
- Helm: `--target helm` produces a chart that passes `helm lint --strict`.
  Unified workload model: `values.service.<name>.kind` = deployment|statefulset.
- Compose: no obsolete `version:` field; `from secret` must mount the secret
  (`secrets:` on the service); multi-port service keeps all ports.

## Import / doctor / parse-error messages (S45–S46)
- **`infra import`** (reverse compiler K8s YAML → `.infra`): `src/infra/importer/`
  (`k8s.py` logic + `__init__.py` helpers) and `src/infra/cli/import_cmd.py`.
  Reads Deployment/StatefulSet/Service/Secret/ConfigMap/Ingress, groups a
  Service matching a workload's pod labels into one `service` block, maps
  postgres/mysql/mongo StatefulSets → `database`, redis → `cache`. Multi-doc
  (`---`) + directories supported. Output to stdout, or `--output` to a file.
  `tests/test_import.py` (~47 tests). Errors: `InfraImportError`; invalid/empty
  YAML must not crash. Key gotcha: **env `from secret/config/field` must live
  inside an `env { }` block**, not as bare service fields, or the round-trip
  fails to parse.
- **`infra doctor`**: `src/infra/cli/doctor.py`, `tests/test_doctor.py`.
  Checks Python (>=3.11), Docker (daemon via `docker info`, not just CLI),
  kubectl, helm, kind, kubeconform, pygls. Tests monkeypatch `shutil.which` /
  `subprocess.run` (NOT fake shell binaries — Windows-safe).
- **Friendlier parse errors**: `src/infra/parser/__init__.py` maps the three most
  common mistakes: unclosed `}` → "Missing closing brace. Did you forget to
  close the block started at line X?", unknown keyword → "Unknown keyword 'X'.
  Did you mean ...?", missing value → "Expected a value after 'field:'. ...".
  `tests/test_parse_error_messages.py` (6 tests). Do NOT put these in
  `test_error_messages.py` — that file covers semantic error codes (E001… etc.).
